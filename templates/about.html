About This Project

The GLOF Early Warning System is an AI-powered, safety-critical environmental monitoring platform designed to predict Glacial Lake Outburst Floods (GLOFs) before they occur. Built for the Efftronics R&D evaluation programme, it integrates deep learning, edge computing, and high-availability ingestion infrastructure to provide actionable hazard intelligence in real time.

🏔️ The Problem We Solve

Glacial lakes in high-altitude mountain regions — the Hindu Kush-Himalaya, Andes, and Alps — are held back by natural dams of ice, rock, and glacial moraine. When these dams fail, the resulting outburst flood travels downstream at catastrophic speed, destroying communities, bridges, and hydropower infrastructure with almost no warning. Existing systems are reactive — they only alert after the flood has already started. Our system is predictive: it analyses 100+ environmental parameters for any target lake and flags elevated risk before the dam fails.

🔬 What Makes This System Different

🧠

BiLSTM Deep Learning

A bidirectional LSTM network reads environmental parameters as temporal sequences, detecting dangerous trends building over days — not just isolated snapshots.

⚖️

SMOTE + Focal Loss

Two-layer imbalance correction: synthetic oversampling generates realistic GLOF training examples; Focal Loss forces the model to prioritise rare hazard events during training.

⚡

Edge Quantisation

The trained model is compressed to a TFLite INT8 binary (~4MB), enabling sub-50ms predictions on compact MCUs deployed directly at glacier field sites — no internet required.

📡

Zero Data Loss Ingestion

An MQTT subscriber with SQLite circular buffer fallback guarantees that no sensor data is lost during storm-induced network outages at remote high-altitude sites.
