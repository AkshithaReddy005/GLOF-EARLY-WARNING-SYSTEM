Output Columns Added to Results CSV

Column Name Type Description
Risk_Class NEW Integer 0 = Low Risk / Safe  |  1 = GLOF Alert
Risk_Probability NEW Float (0–1) Raw sigmoid output — confidence score of GLOF risk
Risk_Percentage NEW String Human-readable probability, e.g. 87.3%
Risk_Label NEW String Full verdict string: ⚠️ GLOF ALERT or ✅ Normal
Inference_ms NEW Float Inference wall-clock time in milliseconds
Engine NEW String Model engine used: TFLite INT8 or Keras .h5
All original columns PRESERVED — All input columns are retained in the output unchanged

Programmatic Access — REST API

For integration with external systems or automated pipelines, use the JSON REST endpoint:

POST /api/predict
Content-Type: application/json

{
  "input_string": "<comma-separated feature string>"
}

→ Response:
{
  "class": 1,
  "probability": 0.8731,
  "risk_percentage": "87.3%",
  "risk_label": "⚠️ GLOF ALERT — High Risk Detected",
  "inference_ms": 14.2,
  "engine": "TFLite INT8",
  "lake_id": "43",
  "latitude": 30.128,
  "longitude": 93.898
}
