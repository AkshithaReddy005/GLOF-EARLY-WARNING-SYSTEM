Our Services

The GLOF Early Warning System exposes its predictive capabilities through multiple interfaces — a visual analytics dashboard, a REST JSON API, a batch assessment pipeline, and an edge-deployable inference engine — making it accessible to field scientists, disaster response authorities, and automated monitoring platforms alike.

🖥️ Core Services

🔬

Single Lake Risk Assessment

Submit a comma-separated feature string for any glacial lake through the web dashboard. The BiLSTM pipeline returns a risk class, probability score, and visual gauge within milliseconds.

  • Real-time BiLSTM inference
  • Risk probability (0–100%)
  • Plotly gauge visualisation
  • Lake location map (Leaflet)
📂

Batch CSV Lake Assessment

Upload a full CSV file containing hundreds of lake records. The system processes every row through the inference pipeline and returns a downloadable results CSV with predictions appended.

  • Bulk processing — no row limit
  • Risk_Class + Risk_Probability columns
  • Original columns preserved
  • Downloadable CSV output
⚡

Edge Inference (TFLite)

The trained model is compiled to a TFLite INT8 binary for deployment on compact field microcontrollers at glacier sites. No internet connection required — sub-50ms on-device predictions.

  • ~4MB model footprint
  • Sub-50ms inference latency
  • Runs offline on Raspberry Pi / STM32
  • Generated via quantize.py
📡

MQTT Sensor Ingestion

A high-availability MQTT subscriber with SQLite circular buffer fallback continuously ingests field sensor telemetry. Zero data loss is guaranteed even during complete network outages.

  • Publish/subscribe on glof/telemetry
  • Offline SQLite disk buffer
  • Auto-drain on reconnect
  • 10,000-row circular cap
📊

Prediction History & Analytics

Every assessment is logged to a persistent SQLite database. The dashboard displays a live history table and aggregate statistics — total predictions, alert rate, and average inference latency.

  • Per-prediction SQLite records
  • Aggregate stats (alert rate, avg ms)
  • Filterable live history table
  • Accessible via /api/history
🔗

REST JSON API

A fully documented REST API allows external systems, mobile apps, and automated pipelines to submit lake feature strings and receive structured JSON prediction responses.

  • POST /api/predict
  • GET /api/history
  • GET /api/stats
  • GET /health

🔗 REST API Reference

POST /api/predict — Single Lake Prediction

curl -X POST http://127.0.0.1:5000/api/predict \
     -H "Content-Type: application/json" \
     -d '{"input_string": "\"43\",\"GL093898E30128N\",30.128,93.898,..."}'

Response 200:
{
  "class": 1,
  "probability": 0.8731,
  "risk_percentage": "87.3%",
  "risk_label": "⚠️ GLOF ALERT — High Risk Detected",
  "inference_ms": 14.2,
  "engine": "TFLite INT8",
  "lake_id": "43",
  "latitude": 30.128,
  "longitude": 93.898
}

curl http://127.0.0.1:5000/api/history?limit=5
